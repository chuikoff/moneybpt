# MoneyBPT — учёт расходов

Мобильное PWA для личного учёта расходов (вдохновлено Money Pro).
**Все данные хранятся только в IndexedDB на вашем устройстве.** Нет сервера, нет аналитики расходов.

Демо (GitHub Pages): https://chuikoff.github.io/moneybpt/

## Возможности

- Добавление расходов: сумма, категория, группа, дата, комментарий
- История с группировкой по дням, фильтры и поиск
- Обзор месяца: итог, разбивка по категориям, недавние операции
- CRUD категорий (стартовый набор ~33 статей)
- Импорт CSV/TSV (UTF-8 и UTF-16), дедупликация при повторном импорте
- Экспорт JSON/TSV, полная очистка данных
- Офлайн-оболочка через Service Worker (vite-plugin-pwa)


## Run

    npm install
    npm run dev
    npm run build

Base /moneybpt/
Privacy: IndexedDB only.
